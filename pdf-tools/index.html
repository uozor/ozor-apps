Guide

How to use it

Pick a task, choose your files, and download the result. Files are processed on your device with the open-source pdf-lib library. Password-protected PDFs may not work.

Steps

  1. Choose a task: merge, extract/split, or images to PDF.
  2. Select your files (PDFs or images).
  3. Click the button and download the result.

Merge, split, and images to PDF

Merge writes a new PDF in the order you select. Split keeps the pages you list, such as 1-3, 5, counting PDF pages from 1 even when the footer says otherwise. Save each page emits one file per page. Images to PDF puts each picture on its own page. The work uses pdf-lib in the browser. There is no upload, no account, and no OCR. Password-protected files need to be unlocked first or the result can be blank.

A receipt packet that will actually email

Ten phone photos dropped in raw can be tens of megabytes. Compress each image to about 1600 pixels and about 75 percent JPEG in the image compressor, then build the PDF here. A packet of already-small JPEGs is the difference between an attachment and a bounce. For print, 200 to 300 pixels per inch at the printed size is enough for ordinary pages. A full letter-size photo at 300 DPI is about 2550 by 3300 pixels. You do not need the 48-megapixel original inside the PDF.

Failure modes

A truncated download, a renamed non-PDF, or an encrypted file fails honestly. Memory, not a hidden page cap, limits very large jobs. Merge in batches if a long photo PDF stalls, and close other tabs. The result is an ordinary PDF, not PDF/A and not a fresh digital signature. Keep the originals. The page has no trash can on a server because the bytes never left the device.

Frequently asked questions

How should I merge, split, or turn scans into a PDF for a real job?

Merge joins files in the order you select them, so name the pieces or select them from first page to last. A contract plus an exhibit should be the contract file first. Split uses a page list such as 1-3, 5 to keep those pages, and Save each page writes one PDF per page when you need to file them separately. Images to PDF places each JPG or PNG on its own page in selection order, which is the right path for phone photos of a receipt stack. There is no fixed page cap. Very large files are limited by the memory of the device because the bytes never go to a server.

Which PDF jobs belong together, and which do not?

Merging is for documents that should travel as one file: a proposal and its appendix, or a set of signed pages. Splitting is for the opposite, when a portal wants one page or you must remove a page you did not mean to scan. Image-to-PDF is for pictures, not for editing the words inside an existing PDF. This tool does not reorder pages inside a file with a drag handle, rewrite text, OCR a scan into selectable words, or compress a PDF the way the image compressor shrinks a photo. If you need a smaller PDF, shrink the images first, then build the PDF.

Why do some PDFs fail or come out blank?

Password-protected files fail or produce blank pages because the page cannot decrypt them. Remove the password in a reader you are allowed to use, then merge the unlocked file. A truncated download or a file that is only named .pdf will also fail; the page tells you when the file does not look like a PDF. Browser memory is the other limit. Close extra tabs and merge in batches if a few hundred photo pages stall. The result is a normal PDF, not a PDF/A archival file and not a certified signed original. Printing to PDF again can flatten annotations.

What are practical file-size and print targets?

A packet you will email should usually stay under a few megabytes. Phone photos dropped straight into a PDF are often several megabytes each. Compress those images to about 1600 pixels on the long side at roughly 75 percent JPEG quality before you convert them to PDF, and a ten-page receipt packet becomes something you can attach. For a packet you will print, 200 to 300 pixels per inch at the printed size is enough for text and ordinary photos. A full-page photo at 300 DPI is about 2550 by 3300 pixels; you do not need a 48-megapixel original in the PDF.

How do I keep client documents private and in order?

The work runs in the browser with pdf-lib. Files are not uploaded to GWB and there is no account. That also means there is no cloud trash can: download the result before you close the tab, and keep your own copy of the originals. Do not merge documents you are not allowed to combine, and do not assume a merged file is still the signed original if you changed page order. A checksum or the file size in your download folder is a simple way to confirm the file finished writing.

What should I do when the page list does not match the document?

Page numbers in the box are PDF page indexes starting at 1, not the printed number in a footer. A file whose first page is numbered 12 is still page 1 in the box. Open the source and count if the footer and the index disagree. Ranges cannot invent pages past the end of the file. If you need pages from two files, merge first or split each file and then merge the pieces. The tool will not silently drop a password prompt and pretend the merge worked.

Private by design: everything runs in your browser. Your files and text never leave your device.
