Guide

How to use it

Add your name, bio and links. Download a QR code PNG for any URL and a ready-to-host bio.html page.

Steps

  1. Type the link or text you want the QR code to open.
  2. Download the QR code as a PNG for print or screens.
  3. Optionally build a link-in-bio page and download bio.html to host anywhere.

A code that stores the destination

The PNG encodes the URL or the text you typed. There is no redirect and no expiry on our side. The code dies only when the destination dies or the print is unreadable. A shortener you do not control can still expire. For anything you will print and forget, encode the final https address. Error correction handles modest damage, not a torn code. bio.html is a single file you host yourself. It does not phone home.

Print sizes

On a card or a table tent, print at least about 2 centimeters (0.8 inches) square, with a quiet white margin. Posters need to be readable from the distance people stand. Black on white scans. Low-contrast brand colors and glossy lamination often do not. Print a proof at 100 percent scale and scan it with a phone in the real lighting. Fit-to-page blurs the modules. A long URL makes the modules smaller. Shorten the address or print larger.

What to encode

A menu PDF or your own page, a booking link, or public contact text. Not a private invoice, not a password, not a Wi-Fi secret you would not paint on the window. Anyone who can see the code can open it. If you want one printed code whose destination can change, point it at a file you host and edit that file. If you want the code itself to be permanent, point it at a URL you will not rename. The barcode maker is the tool for UPC and Code 128. This page is for QR and a simple link page.

Frequently asked questions

Do these QR codes expire, and what is actually inside them?

The code stores the URL or the text you typed. There is no GWB redirect, no click counter, and no subscription that can turn the code off. The code works for as long as the destination still works and the ink is readable. If you encode a link shortener you do not control, that shortener can expire even though our code did not. For a menu or a card you will print, encode the final https address. Error correction is the library default used by the page, which can recover a modest amount of damage, not a code that has been torn in half.

What size should I print, and how do I test it?

For a business card or a table tent, keep the code at least about 2 centimeters (about 0.8 inches) on a side, with a quiet margin of white modules around it. Posters and window stickers should be larger so a phone can read them from the distance people actually stand. Always print one proof and scan it with a phone camera in the lighting you will really have. Dark-on-light works. Light-on-dark and low-contrast brand colors fail. Do not put a logo in the center unless you know the error correction can spare those modules. This generator draws the code, not a branded overlay.

How does the link-in-bio file work?

You can download a single bio.html that lists the links you entered. Host that file on any static host, including the same host as your site. The page is yours. It does not phone home to GWB and it does not insert a tracking redirect. Point the QR code at the hosted file if you want one code that can change when you edit the file, or point the QR code at a single URL if you want the code itself to be permanent. Those are different maintenance plans. If the QR points at a file you later delete, the code is fine and the destination is not.

What should a shop, a cafe, or a freelancer encode?

A cafe can encode the menu PDF or a page on its own site, not a social profile it might rename. A freelancer can encode a booking page or a vCard-style text block of the details they want public. Do not encode a private invoice link or a password. Anyone who can see the code can open the destination. A Wi-Fi password in a QR code on a window is convenient and also visible to the street. The code is not access control.

Why will a code not scan?

The usual causes are too little contrast, too small a print, a missing quiet zone, a glossy lamination glare, or a URL that is so long the modules became tiny. Shorten the URL, increase the print size, and leave white space around the code. Test with a second phone. A code that only scans in the preview and not on paper was printed with scaling that blurred the modules. Print at 100 percent from a PDF or PNG that is not being fit-to-page by the printer dialog.

Is the link uploaded?

No. The PNG and the bio file are built in the browser. There is no account, no analytics on the code, and no hosted landing page unless you upload bio.html to a host you choose. That host, not GWB, then sees ordinary web traffic.

Private by design: everything runs in your browser. Your files and text never leave your device.
